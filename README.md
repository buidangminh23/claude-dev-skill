## What it will be

An agent skill for Claude Code and Codex that keeps your agent current with the tips, playbooks and skills Anthropic's developers publish on [claude.dev](https://claude.dev). It holds short notes written in its own words plus a link to every post, and it reads the original post from claude.dev when the agent needs the full detail. A scheduled job watches the site and releases an updated skill whenever a post is added or changed.
